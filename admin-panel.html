Firebase Architecture & Connection Details

Reference instructions for connecting your own live Firebase project:

1. Configure Credentials: Open js/firebase-config.js and paste your Firebase Web App configuration object from the Firebase Console.

2. Firestore Database: Create a Cloud Firestore database in Native mode. Collections used: news and messages.

3. Firebase Authentication: Enable Email/Password provider in Firebase Console > Authentication > Sign-in method, then create an Admin user in Users tab.

4. Firebase Storage: Enable Storage bucket for uploading news images under news-images/.

5. Security Rules: Deploy the provided firestore.rules and storage.rules files to enforce zero-trust security and role-based permissions.
